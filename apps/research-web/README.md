# Research web

React/Vite UI for setting up runs and checking backtesting logic: results, every
trade with a one-second replay and the exact features behind it, data quality, and
provenance. See the [research UI plan](../../docs/project/metric-explorer.md).

Run `pnpm dev` from the repository root to start the UI on port 4400 and the API on
8001; Vite proxies `/api` to the API. Times are UTC.
