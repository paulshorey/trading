# Research charts

Reusable React/Lightweight Charts components for inspecting market data and trading
experiments, independent of application state and data storage.

`ResearchChart` displays candles, fill markers, and equity in synchronized panes.
`VerticalLinePrimitive` marks events, and `chartConfig` provides UTC formatting and
chart styling. Extend these components to visualize custom metrics and model outputs.

Keep trading calculations in Python. Retain TradingView attribution and the library's NOTICE.
