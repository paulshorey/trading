# Research charts

Reusable React components on Lightweight Charts, independent of application state
and storage. `PriceChart` shows candles (slots without trades stay empty), markers,
dashed price levels, and labeled vertical events; `LineChart` shows a series such as
equity. `chartConfig` provides UTC formatting, with seconds when needed.

Keep trading calculations in Python. Retain TradingView attribution and the library's NOTICE.
